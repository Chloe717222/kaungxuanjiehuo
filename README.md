# 框选解惑

> **专治各种「这是什么？」**

**框选解惑**——框住疑惑，解开疑惑。一个 Chrome 浏览器扩展，由 Huan 创造。

AI 助手叫 **惑惑**，它的工作很简单：你选中看不懂的文字，它用大白话讲给你听，然后一键存进你的知识库。

---

## 为什么叫框选解惑？

**框选** = 鼠标框住你想了解的文字  
**解惑** = 解答你的疑惑  

而 **惑惑**（Huo Huo）是一个把「解惑」变成人格的名字——它不冷冰冰地回答你，它像朋友一样用口语、用大白话、用你能听懂的方式把事情说清楚。

---

## 它能干什么？

- 📖 你看英文文章，选中 `photosynthesis` → 惑惑告诉你「光合作用，就是植物把阳光变成食物的过程」，顺便讲词根词缀、常见搭配、这个词在农业/环保行业里怎么用
- 🤔 你刷新闻，选中「去杠杆化」→ 惑惑说「就是把欠的债还了，减少负债」
- 👤 你查人物，选中「图灵」→ 惑惑告诉你他是谁、为什么重要、有什么值得深入了解的
- 💬 看完解释可以继续追问「再说细点」「举个例子」
- 📝 点一下「同步到知识库」，所有解释自动存到 Obsidian 笔记里

所有英文单词默认当学单词处理——先讲词义，再讲行业特指。日常词也要说它的常见场景。

## 安装

### Edge 浏览器

1. 地址栏输入 `edge://extensions`，回车
2. 打开左下角「**开发人员模式**」
3. 点「**加载解压缩的扩展**」
4. 选择本扩展文件夹 → 确定
5. 右上角出现图标，装好了

### Chrome 浏览器

1. 地址栏输入 `chrome://extensions`，回车
2. 打开右上角「**开发者模式**」
3. 点「**加载已解压的扩展程序**」
4. 选择本扩展文件夹 → 确定

---

## 配置 AI 服务

惑惑需要一个 AI 大脑。点右上角扩展图标，粘贴你的 API Key：

| 服务商 | 注册地址 | 说明 |
|--------|----------|------|
| **DeepSeek** | [platform.deepseek.com](https://platform.deepseek.com) | 最便宜，注册送额度，推荐 |
| **OpenAI** | [platform.openai.com](https://platform.openai.com) | 需要海外支付 |
| **自定义** | 任意 OpenAI 兼容接口 | 支持所有兼容服务 |

注册后在对应网站的「API Keys」页面创建密钥，复制粘贴到扩展里，点「保存并启用」。

## 怎么用

1. **框选** — 在任何网页选中让你疑惑的文字
2. **点击** — 选区旁会浮现 🔍 图标，点它
3. **读懂** — 惑惑弹窗，大白话解释
4. **追问** — 弹窗里直接继续问
5. **存笔记** — 点「📡 同步到知识库」

快捷键：**Ctrl+Q** 打开自由对话窗口。

---

## 保存到 Obsidian

连上 Obsidian 后，每次解释都能一键变成永久笔记。

1. 打开 Obsidian → 左下角齿轮 ⚙️ →「第三方插件」
2. 关闭安全模式 → 点「浏览」→ 搜 **Local REST API** → 安装并启用
3. 点插件右边齿轮 ⚙️ → 点 **Show advanced settings**
4. 勾选 **「Enable non-encrypted (HTTP) server」**
5. 在 **「Non-encrypted (HTTP) server port 27123」** 下面找到 API key → 复制
6. 在扩展图标上右键 → 选项 → 粘贴 API Key → 保存设置
7. ⚠️ 保存时保持 Obsidian 开着

没有 Obsidian 也可以用「📥 下载文件」或「📋 复制内容」。
