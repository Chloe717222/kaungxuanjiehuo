知识库是什么？
一款免费的个人笔记软件（如 Obsidian）。连接后，每次查词的解释可以一键保存为笔记，积累成个人知识库。

怎么获取 API Key？
1️⃣ 打开你的知识库软件 → 左下角齿轮⚙️ →「第三方插件」
2️⃣ 点「关闭安全模式」→「浏览」→ 搜索 Local REST API
3️⃣ 安装并启用插件 → 点插件右侧齿轮 → 点「Show advanced settings」
4️⃣ 找到「Non-encrypted (HTTP) server port 27123」下面的 API key，复制粘贴到上面
5️⃣ 确保 「Enable non-encrypted (HTTP) server」已勾选
⚠️ 需要保持知识库软件打开才能保存
支持多级路径，用 / 分隔。以 .md 结尾的末段为笔记名，否则整个路径为文件夹（自动生成笔记名）。留空则保存在知识库根目录。
填笔记要放置的知识库名字。打开知识库软件 → 看窗口左上角标题栏或左下角状态栏，显示的那个库的名字。如 xx Obsidian。填这个是为了在插件不可用时，启动备用保存能定位到正确的知识库。如果只有一个知识库，不填通常也能用。
