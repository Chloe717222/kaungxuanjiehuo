这是 Local REST API 插件的默认地址，一般不用改。除非你在插件设置里手动改过端口号，否则保持默认即可。
知识库是什么？
一款免费的个人笔记软件（如 Obsidian）。连接后，每次查词的解释可以一键保存为笔记，积累成个人知识库。

怎么获取 API Key？
1️⃣ 打开你的知识库软件 → 左下角齿轮⚙️ →「第三方插件」
2️⃣ 点「关闭安全模式」→「浏览」→ 搜索 Local REST API
3️⃣ 安装并启用插件 → 点插件右侧齿轮 →「Create new key」
4️⃣ 复制生成的密钥，粘贴到上面
⚠️ 需要保持知识库软件打开才能保存
支持多级路径，用 / 分隔。留空则保存在知识库根目录。
填笔记要放置的知识库名字。打开知识库软件 → 看窗口左上角标题栏或左下角状态栏，显示的那个库的名字。如 xx Obsidian。填这个是为了在插件不可用时，启动备用保存能定位到正确的知识库。如果只有一个知识库，不填通常也能用。
